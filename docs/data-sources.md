# Data source decisions

Source documentation checked on 23 November 2026. Pilot files and local completeness are checked during acquisition.

| Decision | Source | Use and caveat |
| --- | --- | --- |
| Pilot terrain | [Copernicus GLO-90 on AWS](https://registry.opendata.aws/copernicus-dem/) | The current pilot uses the 90 m surface model and its water body mask. The nearby public GLO-30 tile URLs returned 404. The exact inputs, dates and checksums are in the [pilot source manifest](../config/quba-sources.json). |
| Higher-resolution option | [Copernicus GLO-30 on AWS](https://registry.opendata.aws/copernicus-dem/) · [Copernicus license and credit terms](https://documentation.dataspace.copernicus.eu/APIs/SentinelHub/Data/DEM/resources/license/License-COPDEM-30.pdf) | Use where public coverage is available. It is a 1-arc-second surface model, about 30 m nominal posting, for profiles and slope. It can include vegetation and structures. Verify tile coverage, NoData, vertical datum and attribution. |
| Terrain fallback and sensitivity | [NASA SRTMGL1 v003](https://doi.org/10.5067/MEaSUREs/SRTM/SRTMGL1.003) · [NASA product guide](https://www.earthdata.nasa.gov/s3fs-public/2025-05/SRTM_Quick_Guide.pdf?VersionId=ZDrZprebSzTuJdC57vPsRXhuXU3S1OZK) | Use the PDF's approximately 30 m dataset if the primary terrain source is unsuitable, or rerun identical scenarios on SRTM to see how the DEM influences the results. Check the download route and Earthdata login requirements. Keep vertical datum and sample alignment explicit. |
| Core settlements, optional access costs | [Geofabrik Azerbaijan extract](https://download.geofabrik.de/asia/azerbaijan.html) · [OpenStreetMap copyright and ODbL](https://www.openstreetmap.org/copyright) | Download a dated extract or pin its checksum. Use mapped villages and hamlets as demand; review duplicate node/area representations, names and missing places. Use roads only for a site-access proxy. Document which road classes count and apply attribution and redistribution terms before sharing extracts or derivatives. |
| Optional population weights | [WorldPop Azerbaijan 100 m data](https://hub.worldpop.org/geodata/summary?id=2) · [WorldPop newer country-file API](https://api.worldpop.org/v3/documentation) | The Azerbaijan catalogue lists 2020 people-per-pixel rasters. Use weights in a secondary scenario after verifying the product, year and terms. Check for a newer Azerbaijan product at acquisition. Sum disjoint catchments or assign each populated pixel once, and report unassigned cells. These are population estimates. |
| Optional district outline | [geoBoundaries AZE ADM2 metadata](https://www.geoboundaries.org/api/current/gbOpen/AZE/ADM2/) | Useful for a map or district filter. The Azerbaijan record cites 2020 boundaries and CC BY-SA 3.0 for its source. Verify Quba's polygon and attribution, or use the pilot's own geometric boundary. |
| Optional land-cover sensitivity | [ESA WorldCover 2021 product manual](https://worldcover2021.esa.int/data/docs/WorldCover_PUM_V2.0.pdf) | Can help screen water and flag forested paths. Land-cover classes alone supply no calibrated clutter loss. Use only after the basic LOS comparison. |
| Context only | [Azerbaijan SDG 9.c.1](https://sdg.azstat.gov.az/en/indicators/484/proportion-of-population-covered-by-a-mobile-network-by-technology) · [ITU Azerbaijan dashboard](https://www.itu.int/en/ITU-D/Statistics/Documents/DDD/ddd_AZE.pdf) · [Azercell network context](https://www.azercell.com/en/about-us.html) | Provide country-level or operator context with date and technology. These figures cannot validate a settlement-level simulated link. The pilot can proceed without representative local coverage measurements. |
| Defer | [OpenCellID downloads](https://wiki.opencellid.org/docs/downloads/overview) | Token access and community observations with uneven completeness. Cell records can help explore existing infrastructure later, after documenting location uncertainty and licensing. Missing records do not establish lack of service, and cell locations do not supply antenna settings or ground-truth coverage. |

For each input record publisher, exact URL or tile/object ID, snapshot or reference year, retrieval date, checksum, terms and attribution, spatial resolution, CRS, vertical datum where relevant, and transformations. Log sample counts, NoData and out-of-bounds checks. Use WGS84 longitude/latitude on export and a locally suitable metric CRS for distances, with coordinate order and units tested. Keep raw inputs in a local data cache and track small metadata and synthetic fixtures.
